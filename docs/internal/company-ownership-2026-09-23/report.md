# Major beneficial ownership — 2026-09-23

Implemented inside the existing company-evidence envelope, SEC transport, atomic update pipeline, Visual V3 profile and read-only Research APIs. No parallel database or ownership provider. No commit, push or deployment.

| SOFI | Seven 13G filings: Vanguard entities, BlackRock 5.1%, JPMorgan 5.1% → 3.7%, Jane Street 5.5% → 2.6% with four reporting persons. Three older SoftBank/Delaware Project 10 13D amendments report 9.0%, 6.9%, 4.9% and a conditional plan to sell some/all holdings. |
| CRWD | Two 13G filings: Vanguard Group's reporting-reorganization zero and separate Vanguard Capital Management 7.27%. No additional history or 13D example was manufactured. |

These are filing-reported figures, **not current holdings**. The 15 published filings cover selected 2025–2026 structured disclosures and separate August 2022 SOFI examples. The [official-source fixture manifest](../../../tests/fixtures/company_ownership/README.md) links every source and exclusion, with hashes. The original SoftBank 13D and amendments 1–3 are outside this bounded backfill.

The model retains filing family/type, issuer, reporting persons, shares, reported percentages, all four voting/dispositive powers, security/CUSIP, filing and event/reference dates, applicable rules, useful source statements, source locations, URLs/hashes, reviewed identities, relationships and amendment/comparability links. Twelve 13G XML sources are parsed. Three legacy 13D HTML sources use explicit cover-page reviews and exact supporting passages; there is no general HTML inference. Filer CIKs are used where established; subsidiaries without verified CIKs receive explicit reviewed identities. Similar names never merge entities. Overlapping parent/subsidiary holdings never sum into a new total.

Amendments remain immutable observations in one reviewed reporting history. Jane Street's XML explicitly supplies its previous accession; other links require source review. Safe comparisons return reported share changes and percentage-point changes, not trades. Vanguard's reorganization breaks comparability. SoftBank's final selected amendment explicitly includes 31,428 RSU-related shares whose earlier scope is unproved, so its position comparison also breaks. Different percentage denominators are disclosed. The factual 13D purpose statement is attributed to that dated filing, with no activist/hostile/strategic label.

UI: clean ownership rows, percentages, shares, filing/reference dates, neutral comparable changes and small history charts with gaps. Four initial rows, progressive expansion, a historical selector only where useful, detailed powers/persons/filings under **Historik & underlag**, and common **Källor & metod**. No complete-shareholder pie, sentiment score or live-ownership claim. Missing reviewed records do not imply absence of large owners.

Research: `NTMCompanyEvidence.ownershipSince` returns verified new filings, amendments and comparable changes without changing saved revisions. First observations mean **first reviewed in this selection**, not a proven newly acquired owner. Same-day publication boundaries are conservative. Final comparison UI remains out of scope.

Automation: `--ownership` incrementally discovers new index entries and retains verified sources. **New documents require review before publishing observations**; pending entries are visible as a freshness limitation. Exact hashes, entity mappings and comparability decisions are in [the source review registry](../../../scripts/source_reviews/company_ownership.json). `--reverify-ownership` re-fetches sources and rejects changes rather than rewriting evidence. Malformed sources, index gaps and outages retain the last verified whole feed. The existing scheduled command includes this layer. CI remains entirely offline. A live re-verification on September 23 passed.

**Locally release-ready for this reviewed pilot.** Limitations: selective history, dated disclosures, manual admission of new sources/relationships, no automatic archival paging or generic legacy parser, no claim to a complete shareholder register. Real comparable examples decrease; increase behavior is tested with clearly synthetic fixture modifications.

**Retain this bounded layer:** SOFI's comparable changes and Vanguard's changed reporting scope add factual context that a filing list misses. Validate user comprehension before expanding it. **Keep 13F deferred**: [quarterly institutional holdings](https://www.investor.gov/introduction-investing/investing-basics/glossary/form-13f-reports-filed-institutional-investment) answer a different question, and this pilot does not establish enough product demand to justify the extra coverage and identity work. Neither 13F nor any excluded feature was implemented.
