# Canonical Visual V3 — production implementation

The approved A2.1 Midnight/Electric art direction and A2.2 typography are implemented on the actual Research and Public Analysis routes. No new visual direction, fixture runtime, public schema, data provider or financial calculation was introduced. Nothing committed, pushed or deployed.

1. **Production architecture.** `research.html` and `analys.html` load scoped canonical tokens before `research-v3.css`. Existing modules retain data, storage, authentication, publication and lifecycle ownership. The Public Analysis renderer changes only its own branch in `social-ui.js`.
2. **Tokens/styles.** `visual-v3-tokens.css` maps the canonical palette to existing semantic names, with reusable fonts, buttons, focus, header and theme primitives. Only `body.visual-v3` activates them. The Wave 1A component stylesheet was edited in place. No prototype stylesheet or fixture renderer is loaded by production.
3. **Typography.** Georgia/Times New Roman supplies company titles, financial values, report reading and the first-layer writing fields; Segoe UI/Arial supplies controls and metadata. Titles use 98/62px Research and 113/74px Public desktop/mobile limits. Primary numbers use 57/48px, supporting mobile values 33px. System fonts require no licensing distribution or network loading.
4. **Color/themes.** Canonical canvas, surfaces, text, cyan/petrol actions, semantic states, separators and focus are scoped to these pages. Original logo remains. Theme control is circular. Green remains a positive semantic role.
5. **Overview.** Real legal company name, profile, fiscal metadata and contextual thesis action remain prominent. Three leading metrics use an open ruled financial band. Company limitations and all remaining financial/valuation depth remain reachable.
6. **Selector.** Existing searchable supported catalogue, current selection, Escape/focus return, no-result status and manual-entry path remain. No second permanent company inventory was added.
7. **Financial metrics.** Standard profiles lead with revenue, FCF and existing normalized diluted EPS when available; financial services lead with revenue, net income and EPS. Missing metrics fall through to available evidence and existing limitation notices, rather than becoming zeros. Formatting separates Swedish values from explicit USD/million/billion/per-share units. Values and provenance are unchanged.
8. **Chart.** Native CSS bars use the existing validated annual series, a zero baseline, gaps, actual fiscal labels and visible units. Historical bars are outlined; latest is accented. Keyboard/click opens the existing period provenance dialog; Escape returns focus. The exact-value/source table remains. No chart dependency was added; deep Chart.js charts remain existing dependencies.
9. **Provenance.** Existing human-readable basis, dates, filing/taxonomy detail and dialog behavior remain intact. Sources are accessible from financial metrics, each chart bar and the table. Reading notes distinguish annual periods from TTM without inventing company conclusions.
10. **Thesis.** Investment idea, falsification and review date remain the first layer. Editorial writing typography supports long actual input. Assumptions, questions, notes and risks remain progressively disclosed. Existing save behavior is retained; no new autosave or draft persistence promise.
11. **Lifecycle/deep states.** Contextual due/change/saved actions, reviews, version history, comparison, outcomes/checkpoints, manual thesis and publication flows retain their owners. The 38-test browser suite covers these paths; stress checks additionally save/reload a long thesis and enter advanced depth. Unsaved edits keep the pre-existing behavior.
12. **Public Analysis.** Real current snapshots render an upright company masthead, linked username, separate publication/analysis dates, ownership statement, reading column and quiet section index. Empty optional fields are omitted. Existing author administration remains in account/Research rather than becoming dominant report chrome. No new public financial appendix, valuation, chart or field was introduced. Existing safe selected assumptions/risks remain the same contract.
13. **Mobile.** 360/390/430px were exercised in both themes, along with the existing practical 320px/zoom checks. All five representative company names remain near the top. Long names wrap; metric labels can shrink/wrap beside their source buttons. Exact-value tables scroll locally. Physical mobile keyboard testing was not available.
14. **Theme parity.** Core overview, new/existing/deep thesis, selector, provenance, due review and public report captures exist in light and dark. Long/minimal public snapshots and five company profiles also pass both themes.
15. **Accessibility.** Existing headings, skip link, labels, statuses, native disclosures, dialog focus and reduced motion are preserved. Chart uses a named group containing real source buttons, not an image role hiding interactive children. Scoped palette text checks have a minimum 5.61:1 canvas contrast; existing actual control contrast checks require 4.5:1. Practical accessibility/CSP checks cover 36 page/views. This is not screen-reader certification.
16. **Performance.** Compared with the task-start baseline, component CSS grew about 3.57KB and scoped tokens add about 2.92KB before legacy-rule removal; production JS grew 2.37KB across three existing scripts. One small local CSS request is added. No font request, new remote request or chart library. A cold uncompressed localhost Research sample: 31 resources, about 1.55MB decoded, about 207ms DOMContentLoaded; existing shared scripts/data dominate. These timings are observations, not a before/after speed claim or field Core Web Vitals. Exact deltas and asset inventory are in the QA JSON files.
17. **Cleanup.** Removed the legacy metric dashboard/card block and responsive rules from `style.css` (78 lines), plus superseded dashboard/metric rules from `premium.css`. Repository search confirmed the component is rendered only by Research. Retained shared styles still used by unrelated pages and the isolated design reference.
18. **Prototype differences.** Real legal names may wrap more than the short NVIDIA fixture. Existing global/local navigation and explicit financial section/period add vertical space, so the chart begins lower. Real metadata and limitation notices are retained. Financial-service/missing-data summaries differ deliberately. Public reports have no invented subtitle or future financial appendix. Saved thesis remains the actual editable form with lifecycle controls, rather than the fixture's simplified reading/edit simulation. Deep tools retain their actual functional structure.
19. **Screenshot review.** Pass 1 was captured and compared directly with the approved overview. Critique: missing EPS in the leading band, weak column separation, chart without margin context and legacy public-copy specificity. Pass 2 added existing EPS, column rules, chart reading margin, corrected public reading size, narrow label wrapping and removed obsolete metric styles. Final review also corrected a default-blue margin link and compact-grid specificity. [Gallery](../qa/visual-v3/production/gallery.html), [pass 1](../qa/visual-v3/production-pass1/contact.jpg), [final pass](../qa/visual-v3/production-pass2/contact.jpg).
20. **Tests changed.** Browser expectations now distinguish scoped V3 colors from unchanged V2 pages and expect three leading metrics. Social browser assertions apply the new canvas only to Public Analysis. Research test navigation now handles ticker URLs containing fragments. Added `scripts/visual_v3_production.py` for multi-company, public stress, long saved text, chart keyboard/focus, contrast and overflow checks; existing `visual_v3.py` supplies the two-pass captures.
21. **Validation.** Release gate: 166 Python tests and 222 JavaScript tests pass with PGlite configured, no skips. Full browser suite: 38 pass. Social browser and SDK/session browser pass. Actual local PostgreSQL cloud RLS, social RLS and publication migration checks pass. Practical accessibility/CSP: 36 views pass. Stress: 106 states pass. SEO: 85 canonical sitemap URLs, zero stale artifacts. Staging/local references, credential-pattern/CSP scans and `git diff --check` pass. Existing partial macro/future-calendar notices remain unrelated. See logs under `docs/qa/visual-v3/production/`.
22. **Files changed in this task.** `visual-v3-tokens.css`, `research-v3.css`, `research-v3.js`, `research.js`, `social-ui.js`, `research.html`, `analys.html`, `style.css`, `premium.css`, `scripts/browser_smoke.py`, `scripts/test_social_browser.py`, new stress script, specification/report and QA artifacts. Earlier uncommitted Wave 1A/design work was preserved. Generated account regression captures were copied into this task's QA folder; older tracked capture files were restored to avoid unrelated artifact churn.
23. **Remaining limitations.** Public screenshots use intercepted contract-shaped snapshots in test contexts because local production cloud configuration is disabled; no fake content is shipped. Hosted Supabase/live production configuration was not exercised. Chromium is the automated browser; physical devices, Safari/Firefox and screen readers remain unverified. System-font rendering varies by platform. The pre-existing unsaved-edit/draft behavior is unchanged. Twenty-seven protected data/formula/lifecycle/security files match the pre-implementation baseline hashes; no data or schema edits.
24. **Release readiness.** Ready for production integration/review based on the local release, browser, contract and database gates. It is not an unconditional hosted-deployment sign-off: validate the intended hosted environment and remaining device/accessibility acceptance before deployment. No commit, push or deployment was performed.

## Launch the real local routes

```powershell
Set-Location 'C:\Users\Mirne\Desktop\investment-site'
python -B -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/research.html?ticker=NVDA`; use the contextual action or `#thesisSection` for your local thesis. Other verified tickers: SOFI, CRWD, FLY, CRWV. Theme uses the existing header/mobile-menu control. Public production route is `analys.html?id=<real-published-id>` and requires the existing configured service; a bare local server intentionally does not invent published analyses. To inspect offline verified public captures, open `http://127.0.0.1:8000/docs/qa/visual-v3/production/gallery.html`.
