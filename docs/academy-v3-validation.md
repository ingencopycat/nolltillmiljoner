# Academy V3 final report

Completed locally on 2026-09-15. No commit, push or deployment. Existing Academy, Research and calculator functionality is retained.

1. **Progression architecture:** data-driven catalog, validated immutable local history, pure progression projection, shared interactive UI and static page generation. See [architecture and authoring guide](academy-v3.md).
2. **Roadmap:** ten open stages: start, saving/costs, return/currency, metrics, statements, valuation, portfolio risk, macro, research/thesis and advanced application. Two desktop columns become a vertical mobile journey. Explicit status text accompanies styling; stage contents use keyboard-accessible disclosures.
3. **XP:** centralized 5/3/5/15/40/60/25 rewards for lesson/question/exercise/scenario/challenge/case/path. Reward identities prevent farming through reloads, retries, shared questions and repeat imports. No page-open or tool-open XP.
4. **Levels:** five levels at 0/60/180/400/750 XP, visible total and next-level progress. Names describe Academy activity without claiming professional credentials. The final threshold is attainable.
5. **Skill map:** the six existing catalog domains retain consistent IDs and show lesson, exercise, scenario, project and case counts with percentages. Current lesson revisions reduce current progress while retaining previously earned XP.
6. **Scenarios:** reusable context, choice/numeric/multiple-answer controls, explanation, attempt history, completion and canonical lesson/tool links. Incorrect attempts are saved without storing answers.
7. **Challenges:** four projects require several objective checks plus a written self-review. Partial progress survives reload. Reflection text stays only in the form; users are told it is not automatically assessed.
8. **Cases:** two clearly synthetic datasets cover cyclical earnings/cash generation and debt/dilution. They connect to real Research tools without representing their invented figures as real-company data.
9. **Quiz expansion:** 20 new canonical objective questions, plus the existing 11 checks integrated into the shared reward/history engine. Supported formats include multiple choice, numerical tolerance, true/false and select-multiple, embedded in scenarios and projects.
10. **Achievements:** ten deterministic milestones, covering first/tenth lessons, first check/scenario/project/case/path, all scenarios, valuation application and an exercise thesis. Repeated activity cannot duplicate achievement identities.
11. **Recommended next:** transparent prerequisite rules, unfinished activities, latest ongoing lesson, then roadmap order. A new user sees “Starta här”; returning users see “Fortsätt”. No AI service is involved.
12. **Tool/Research integrations:** canonical relations connect lessons and activities to existing calculators, manual thesis and Research destinations. Session links support previous/next, roadmap and exit. External practical actions are optional and do not generate speculative rewards.
13. **Initial counts:** 29 retained lessons; 29 interactive activity pages comprising 15 exercises (11 legacy checks plus four focused exercises), eight scenarios, four challenges and two cases; 20 new objective questions; six project/case self-review steps; ten achievements; ten roadmap stages; five XP levels; six skills and six existing paths. Questions reused across activities are counted once in the canonical total.
14. **Backup/cloud:** outer backup schema 3 persists; inner Academy schema upgrades to 2 with attempts. Full round-trip, deduplicating merge, conflict rejection and old Academy V2 import pass. Current cloud rows/queues still exclude all Academy history. No login is needed; future sync needs a dedicated collection.
15. **Future Pro tier:** `free`/`pro` metadata is supported without filtering, locks, payment or premium messaging. Every initial object is free. Local progress is user-controlled, not secure certification.
16. **Files changed:** new `academy-activities.js`, `academy-progression.js`, `academy-v3-ui.js`, `scripts/build_academy_v3.cjs`, `scripts/academy_v3_quality.cjs`, V3 tests and these guides; updates to Academy progress/UI/CSS/builders, local backup, Min NTM, relation/event catalogs, knowledge-bank validation and browser/quality suites. Generated home/29 lessons and 29 new activity pages are updated; generated post pages load the activity catalog for canonical relations. `premium.css` supplies compact Min NTM progress styling.
17. **Tests:** 12 new V3 unit tests plus one added backup/attempt/cloud test; existing generated-page and analytics assertions updated. A new end-to-end V3 browser flow covers XP, wrong answers, retry, reload, partial project, final project/case, level, achievements, skills, current path, Min NTM, full backup and V2 migration. Three activity views join the accessibility/CSP suite.
18. **Browser/screenshots:** Edge/Chromium 153.0.4234.32 in fresh contexts. Roadmap checked at 360/390/430 in both themes, including keyboard disclosure navigation. Inspected roadmap, Min NTM, XP summary, scenario, project and case screenshots. Visual review found a cramped numeric label and redundant Min NTM navigation; both were corrected. [Selected local evidence](qa/academy-v3/README.md) is retained.
19. **Validation:** full Python suite: 163 run, 162 passed, one optional database test skipped because `PGLITE_MODULE` is absent. JavaScript: 195 passed. Browser: all 36 passed; the three Academy browser flows passed again after final navigation/live-region refinements. Accessibility/CSP: 28 views in both themes at desktop/320px, with final activity CSS rechecked. SEO: 58 canonical sitemap URLs; all activity pages deliberately noindex. Relations, backup, staging/local references, calendar/rules and `git diff --check` pass. These are practical checks, not an exhaustive accessibility audit or real-user performance measurement. Existing partial macro/future-calendar notices remain unrelated to Academy.
20. **Remaining gaps:** self-reported lessons and self-reviewed writing do not prove understanding; no semantic grader, external Research-action reward or Academy cloud collection is included. Editing browser storage can alter progress. No real learner-outcome or 500-object browser benchmark has been claimed. Reflection drafts disappear on navigation; completed step records remain. Stable IDs support expansion, but future catalog retirement/reward rebalancing needs explicit migrations.
21. **Completion:** the requested initial V3 scope is implemented and locally validated, with no known release blocker from these checks. It is ready for product review and has not been published.
22. **Wait for real users:** adjust XP balance, level thresholds, roadmap order, explanations and challenge difficulty using observed confusion and completion patterns. Add deeper cases and reviewed real Q&A in response to evidence. Defer payment, locks, AI tutoring/grading, certified claims, leaderboards and a much larger catalog.

Reproduce with `python -B scripts/validate_release.py`, `python -B scripts/browser_smoke.py`, and `python -B scripts/quality_browser.py --output <report.json>`. Set `NODE_BINARY` if Node is not on PATH and `NTM_BROWSER_CHANNEL=msedge` to use the installed browser. Validation never publishes or commits.
