# Focused menu, money-input and compound-calculator improvements

Implemented and validated locally on 2026-09-15. No commit, push or deployment. Existing Academy and Research work is preserved.

1. **Menu:** the shared navigation now has a fixed pointer-blocking backdrop and a consistent layer above dense Research content. Opening either mobile navigation or the desktop learning dropdown makes background body content inert and locks body scrolling. Escape/backdrop closes and restores the opener; Tab/Shift+Tab wrap inside the header. Link navigation and viewport changes close the overlay. Previously inert content and the original overflow style are restored.
2. **Live grouping:** the existing money-field allowlist is unchanged. Fields use a real grouped text editor with decimal input mode. Caret/selection mapping counts non-separator characters; deletion beside a grouping space removes the adjacent digit. Decimal dot/comma, negative text, paste and composition are supported. Rates, EPS, share counts and multiples remain native number inputs. The per-element `.value` adapter returns the ungrouped numeric string; `.valueAsNumber` returns its number. Existing calculator reads and snapshots therefore remain numeric. Original min/max/step/required constraints are checked with a native numeric validator and reported through custom validity. Negatives remain invalid where the field or calculator prohibits them.
3. **Naming:** primary heading, metadata, tool-directory label, recent-tool name and saved-tool label now use “Ränta-på-ränta-kalkylator”. Supporting text identifies an investment/savings calculator. `ranta-pa-ranta.html` and its canonical URL are unchanged; no redirect was introduced.
4. **Yearly mode:** optional “Avkastning år för år” disclosure in the existing growth form, with one input row per year. It supports 1–100 whole years, returns from −100%, and an explicit return-to-constant button. The default constant calculation is unchanged. Results and chart change only on Beräkna. Edits and restored scenarios preserve the existing neutral/calculated/stale behavior. Constant illustrative comparison cards are hidden when the calculated result uses a yearly path.
5. **Mathematics:** each year's net factor is `(1 + return/100) × (1 − fee/100)`. Its twelfth root is applied monthly, then the fixed nominal monthly contribution is added at month end. Inflation deflates the final value by `(1 + inflation/100)^years`. The same fee-free path supplies the fee-impact comparison. A −100% year follows this explicitly disclosed monthly smoothing convention, so only the final month's contribution survives that year. The result distinguishes arithmetic mean from geometric/CAGR return **of the return series before fees and without contributions**, not a misleading account balance CAGR. The example `[50,25,40,-10,15]` grows 100 to 271.6875 without fees/contributions; its arithmetic mean is 24%. Academy CAGR help resolves through the shared concept hook.
6. **Storage/backup:** yearly mode, year count and row values use the existing scenario form snapshot. The scenario and backup versions do not change. Legacy snapshots without the new checkbox restore constant mode. Restore builds rows before assigning saved values. Missing, invalid or non-finite active yearly entries are rejected by the shared scenario reader/save validation, so JSON backup imports also reject malformed series before writes. Money snapshots retain type `number` and raw values.

11. **Limitations:** yearly returns assume even monthly growth within each year, not actual market timing. Native spinner buttons are replaced only on the selected grouped money editors; decimal keyboard layouts depend on device. External scripts reading the native HTMLInputElement prototype or FormData directly will see display text with separators, while NTM's ordinary `.value`/snapshot consumers receive raw values. Future consumers should use the shared adapter rather than parsing display text. No exhaustive assistive-technology certification or real-device iOS testing is claimed.
